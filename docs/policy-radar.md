# 政府项目申报雷达

## 判定规则

规则按以下顺序执行，前面的硬性不适用条件优先：

**前置准入规则：政府政策文件**是指政府机关或依法受权机构发布的正式规范、指导或执行性文件；至少应能识别出正式文件名、申报/征集文件形态或正式行文依据。政府官网发布的新闻、会议报道、调研动态和服务案例不是政府政策文件，不能因发布主体是政府部门而入库。标题和正文均未呈现正式文件形态，或标题属于新闻、会议动态、活动报道、服务案例的，均直接丢弃。例如“个人医保云为抢救患者争取了宝贵时间”属于医保服务案例，而非政策文件。

1. 已过截止日期、活动已结束、新闻/喜报/调研、合作/会务、结果公示或名单，判为“直接丢弃”。标题为“关于……的若干意见”的长期指导性文件也直接丢弃；若政策库标题只是章节名，但原文开头明确为“印发/发布《……若干意见》”，同样丢弃。即使正文写有扶持措施也不作为可跟进项目。“再创新高”“全省/全市第一”等成果新闻，以及标题无申报动作的合作通知也直接丢弃。它们只参与本轮内部审计，不会写入公开 JSON，因此不可能出现在前端。
2. 已读取原文且仍在有效期的“产业供给能力/供给方/技术产品解决方案”正式征集，若企业可以报送，判为“供给方征集”。这不是资金申报，但可作为溯驭的技术、产品或解决方案供给机会跟进。
3. 明确只面向其他城市/区县、纯政策入口、排除行业、地方政府申报主体等，判为“不匹配”，可在“全部”中复核。
4. 未命中氢能、电控/电力电子、低空经济、新型电力系统等核心赛道，且未命中公司已核验资质，判为“不匹配”。
5. 官方原文尚未读取、读取失败、扫描件/加密件无法提取或格式暂不支持，原则上判为“待查”；但这不会覆盖第 1 条的直接丢弃规则。往年申报、跨年度发布但未提供有效截止日期的申报，或正文明确的申报日期区间已结束时，也会直接丢弃。
6. 原文已成功读取时，标题是否完全一致、是否出现旧版“申报信号”只作为诊断信息，不是准入条件。
7. 邀请制但缺少企业邀请凭证，或公司资质明确不满足/尚未核验，判为“待查”。
8. 支持对象、申报主体、申报条件、支持方式、截止日期五项原文证据中，命中任意一项即判为“可申报”。五项齐全仍保留为证据完整度信息，但不再是强制门槛。
9. 原文已读取但五项证据都没有命中，判为“待查”。

页面只显示可行动队列：可申报、供给方征集，以及时间未过且非活动的待查事项。`ineligible`、`opportunity` 和 `discarded` 仅用于同步审计计数，不写入页面记录，也不再提供顶部筛选标签。

## 长期官方来源

同步程序直接访问政府公开栏目或政府 JSON/XML 接口，不依赖人工搜索结果。重点来源包括：

- 江苏省：科学技术厅、工业和信息化厅、发展和改革委员会、知识产权局的 WebBuilder 结构化通知，及省政府文件栏目。
- 苏州市：市政府政策文件库，科技局、工信局技术创新/技改投资/节能/企业服务、发改委、市场监管局、商务局等官方栏目。
- 吴江区：吴江区人民政府 `appsearch/wjapi/list` 官方 JSON 搜索为主，区科技创新公开信息栏目为辅。
- 国家、浙江、杭州、连云港来源继续保留，不因地区优先级而丢弃。

每次同步先收集全部索引、全局去重，再按“截止日期仍开放 → 当前年度 → 吴江/苏州/江苏 → 核心赛道”计算正文读取优先级。未进入当次读取额度的记录依然保留为待查。

## 正文与附件解析

- HTML 正文会读取其中最多 3 个 PDF/DOC/DOCX 附件。
- PDF 由 `pdfjs-dist` 解析；新旧 Word 文件由 `word-extractor` 解析。
- 使用文件魔数与 MIME 类型判断真实格式，避免将错误页 HTML 当成 PDF。
- 文档大小、PDF 页数和提取字符数均有上限；读取失败会保留原链接并进入待查。

## 运行与保护

```bash
npm run sync:policies
npm run test:policy
```

可选环境变量：

- `POLICY_SYNC_DETAIL_LIMIT`：每次最多读取的正文数，默认 240。
- `POLICY_SYNC_CONCURRENCY`：正文读取并发数，默认 6，最大 12。
- `POLICY_SYNC_HOST_DELAY_MS`：同一政府域名两次正文请求之间的间隔，默认 120 ms；同域名不并发，用于降低 WAF 限流。
- `POLICY_SOURCE_PAGE_LIMIT`：结构化栏目每次最多页数，默认 6。
- `POLICY_DOCUMENT_MAX_BYTES`：单个正文/附件的最大字节数，默认 20 MB。
- `POLICY_DOCUMENT_TIMEOUT_MS`：正文请求的单次超时，默认 20 秒；每条最多尝试 2 次。同域名连续失败 2 条后本轮会触发熔断，余下记录保留待查，下一次定时同步再重试。
- `POLICY_PDF_MAX_PAGES`：单个 PDF 最多解析页数，默认 80。

同步在写入前执行端到端完整性检查。如果有公开候选记录，但“可申报 + 供给方征集 + 可争取 + 待查”全部为 0，程序会报错并保留上一版文件。通过检查后才原子替换 `public/policies.json`；若已有 `vinext` 生产构建，同时更新实际对外服务的 `dist/client/policies.json`。
