# 设计规则

本文件是当前实现的约定。Fernand 原站测量及差异见 [研究记录](research.md)。

## 1. 画布优先

完整工作页面由导航、主工作区、上下文区域构成。三者沿同一连续画布展开，用 1px 细线表达边界。

- 一个按钮无需先放进一张卡片。
- 列表无需先放进一张卡片。
- 不给侧栏再加圆角、白色底板和外层阴影。
- 只有独立的实体、菜单、弹层、聊天窗等需要额外表面。
- 「卡片嵌套卡片」不是默认布局手段。

这条约定来自此次视觉评审：第一版层层白卡片的组织方式被否定，第二版连续画布已通过。

## 2. 三种画布

| 类型 | 类名 | 内容层级 | 适合场景 |
|---|---|---|---|
| 连续工作画布 | `ui-canvas ui-canvas--floral` | 樱花 → CSS 渐隐 → 页面内容 | 工作台、上传、核对 |
| 纯净画布 | `ui-canvas--quiet` | 单层底色 → 内容 | 表格、设置、密集数据 |
| 流程画布 | `ui-canvas--dots` | 16px 点阵 → 连线与节点 | 规则、自动化 |
| 樱花展示画布 | `ui-canvas--blossom` | 原图 → 独立小组件 | 组件预览、空状态 |

工作画布的花图和渐隐层为纯装饰，使用伪元素、`pointer-events: none` 和隔离层叠上下文；不覆盖交互事件。花不滚动、不持续漂移，也不穿过文字内容。

## 3. 字体

英文和数字使用本地 Inter 3.19。中文依次使用 PingFang SC、Noto Sans SC、Microsoft YaHei 和系统字体；中文字体未打包，具体字形取决于设备。

| 用途 | 字号 / 行高 | 字重 |
|---|---|---|
| 规范首页标题 | 38–43 / 48–56 | 400 |
| 模块标题 | 24–30 / 31–38 | 400 |
| 薪资页主操作标题 | 23 / 32 | 400 |
| 正文 | 14 / 22 | 400 |
| 常规控件 | 13 / 20 | 500 |
| 辅助说明 | 12 / 20 | 400 |
| 展示用紧凑小组件 | 9–12 / 14–18 | 400–500 |

表格金额使用 `font-variant-numeric: tabular-nums`。较粗字重只用于短标签和关键强调，避免整页粗体。营销网站的大型标题与模块空隙不直接套用到业务页面。

## 4. 语义色

使用变量表示角色，避免业务组件引用原始颜色。`ink` 为标题，`text` 为正文，`muted` 为辅助信息，`faint` 只用于非必要弱提示与禁用状态；不能用颜色作为唯一状态区别。

- 薄荷主题的标记色为 `#58B68E`；小文字使用更深的 `accent`。
- Fernand 原始强调蓝 `#00A0FF` 保留在参考主题中；小文字也有更深的 `accent`。
- 状态有圆点、文字和颜色。错误信息靠近出错字段。
- 深色模式同时切换画布、表面、文字、边界、阴影和状态色，不能只替换底色。

所有实际值以 [tokens.json](../tokens/tokens.json) 为准。

## 5. 控件密度

| 项目 | 约定 |
|---|---|
| 基础间距 | 4、8、12、16、24、32、48px |
| 小 / 标准 / 大按钮 | 28 / 34 / 40px |
| 输入框 | 36px，圆角 4px |
| 普通按钮圆角 | 6px |
| 浮层圆角 | 8–10px |
| 主要点击区域 | 触屏时至少 40px 高；复杂内容可以更高 |
| 图标 | 24px 网格、1.6px 线宽，常用渲染 18px |
| 天数输入 | 组件库 66px，薪资页 62px；不拉伸填满一行 |

胶囊按钮用于上传、进入完整体验等相对独立的入口。表格行操作主要使用文字链接。`ui-card` 仅用于独立上下文实体，不作为常规容器。

## 6. 阴影

静态分栏：没有阴影。按钮：短投影加淡轮廓。弹出的菜单、对话框与聊天窗：更明显的 8px / 32px 抬升阴影。

```css
/* 控件 */
box-shadow: 0 2px 4px #12376914,
            0 1px 1px #1237690a,
            0 0 0 1px #12376914;
/* 临时表面 */
box-shadow: 0 8px 32px #12376929,
            0 0 0 1px #12376914;
```

## 7. 动效

| 类型 | 时长 | 曲线 / 特征 |
|---|---|---|
| 按钮、开关、颜色变化 | 160ms | 简短直接 |
| 分段器、菜单 | 180–240ms | 缓出 |
| 对话框进入 | 300ms | `cubic-bezier(.34,1.56,.64,1)`，轻微回弹 |
| 抽屉进入 | 300ms | `cubic-bezier(.19,1,.22,1)` |
| 进度填充 | 600–650ms | 缓出，不循环 |
| 展示过渡 | 750ms | 舒展缓出 |
| 持续动画 | 仅明确的加载状态 | 状态结束即停止 |

不增加无目的的整页呼吸、持续扫光或花卉运动。`prefers-reduced-motion: reduce` 会将动画与过渡缩短到近乎即时；`data-motion="off"` 可在组件页手动关闭。状态变化在减少动态模式下仍清楚可见。

## 8. 响应式决策

这里按内容需要设置断点，并未硬编码浏览器批注尺寸。

- 组件库：1100px 以下缩窄说明列；900px 以下示例分组改为上下排列；640px 以下左侧目录改为可打开的抽屉，关闭后不可聚焦。
- 薪资页：1180px 以下收紧三栏；960px 以下右侧摘要移到内容下方；640px 以下左导航保留图标，`aria-label` 提供完整名称。
- 四步进度始终完整显示，不把最后几步裁切在容器外。窄屏将数字与名称上下排列。
- 输入与表单允许自然换行，表格只在自己的容器内横向滚动；页面本身不横向溢出。
- 画布预览中的 Popup / Modal / Drawer 是缩小演示尺寸，不作为产品浮层的固定生产宽度。

## 9. 真实进度

`current` 表示正在查看的位置，`completed` 表示完成记录，`available` 表示最远可进入位置。三者独立。

1. 完成当前步骤前调用业务验证函数。
2. 前面的步骤可回看；回看不清除或新增完成状态。
3. 替换基础资料或修改参数时，清除当前及后续完成状态。
4. 文件被选择、页面被打开、鼠标点过某一步，都不等于业务完成。
5. 实际产品需要将「文件解析成功、字段校验通过、计算成功、员工核对完成」连接到对应验证条件。
