# 研发费用管理平台前端设计稿

这组高保真设计稿基于现有浏览器本地研发成本测算功能，以及用户提供的企业后台参考界面生成。

页面包括：

1. 月度核算总览
2. 资料上传与智能识别
3. 研发工时核算
4. 研发项目成本台账
5. 复核中心与成果导出

设计重点：本地安全处理、核算流程可视化、工时与费用可追溯、异常分级处理、固定 31 表模板复核。

## 三模块修订稿

根据后续反馈，侧边栏统一收敛为三个入口：`研发费用`、`工资表`、`项目申报`。

- 研发费用总览修订：移除“总览”等多余导航入口。
- 研发费用上传页修订：只展示工资表、工时表、明细账、科目余额表；文件上传后对应资料卡变绿。
- 工资表：九类工资源表上传与后续字段映射流程。
- 项目申报：项目材料、完整度、审批阶段与待办事项。

## 溯驭财务 V3

品牌区统一使用用户提供的 SEEEx 斜纹标识并显示“溯驭财务”，全局顶栏右侧保持留白。项目申报调整为政府项目选择流程，分别提供“待选项目”和“已选项目”两个状态页。
