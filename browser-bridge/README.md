# 薪资邮件填充助手

这是一个本地 Chrome/Edge 扩展，不上传工资数据，不点击“发送”。

## 安装

1. 打开 Chrome 或 Edge 的扩展管理页：`chrome://extensions/` 或 `edge://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录 `browser-bridge`。
4. 安装后刷新薪资测算系统页面。

## 使用

在薪资测算系统的邮件校准页点击“打开企业微信邮箱”。扩展会接收本次校准后的收件人、主题和正文，登录企业微信邮箱后自动进入写信页并填入内容。

附件仍需在邮箱页面手动选择，发送必须由用户最后核对并点击。
