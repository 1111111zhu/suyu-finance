# 工资数据库第一版验收记录

## 交付范围

基于 `d84540bc464f0523cbb301ee99fee6f1d19ee39d`，实现 PostgreSQL 数据库基础、版本迁移、数据访问层、字段映射、虚拟样例、数据库容器配置和备份恢复工具。

本阶段尚未连接工资页面、提供登录或工资 HTTP 接口、上传真实工资文件、连接存储机器或部署生产服务器。工资计算由后续后端传入版本化结果；数据库不重新裁定工资规则。

## 数据库验证

使用本机 PostgreSQL 17.11 的隔离临时实例执行集成测试，测试完成后停止实例并清理临时数据。测试对象均为虚拟员工、虚拟公司及虚拟工资。

2026-09-15 最终结果：**38 项字段与工具测试、27 项真实 PostgreSQL 集成测试全部通过，无跳过项**，合计 65 项。新增数据库代码与测试的 ESLint 检查通过。

验收覆盖：

- 迁移重复运行与校验和、事务回滚、角色权限。
- 同名和重复参考工号、人员显式关联、入离职、调岗、复聘及原子跨公司调动。
- 同月多批次、多公司数据、两阶段来源隔离、导入版本不可变。
- 金额精度、空白和零、公司汇总与工资明细勾稽。
- 重复提交、并发写入冲突、中途失败不留下部分工资结果。
- 归档与修订、历史快照保护、输入变更后的过期结果阻断。
- 邮件正文依据过期检测、确认与复核状态保护。
- 重新建立数据访问对象后读回未完成批次、来源资料、调整和复核；日期及补班日期跨时区保持一致。
- 原始文件哈希保护、数据库与文件元数据共享备份快照、只恢复到新数据库。

可重复执行：

```bash
npm run test:db
npm run test:db:integration
npx eslint database/payroll 自动化测试/payroll-db*.mjs
npm run build
```

完整网站 ESLint 为 0 errors；已有页面和第三方压缩脚本有 36 个 warnings，新增数据库模块定向 ESLint 无警告。网站生产构建通过。

本机没有 Docker，未启动 Compose 容器；本次数据库验证使用原生 PostgreSQL 17.11。CI 配置包含 Compose 语法检查，但尚未推送执行。CI 使用外部测试库时会明确跳过两项依赖本机隔离实例的备份恢复测试；这两项在上述本地验收中均已实际通过。
