## 费用契约

上传资料 → 固定模板计算引擎 → 逐项目/类别金额 → PostgreSQL 事务入账 → 项目合计 → 平台合计。
金额取自生成 Excel 的 master_costs 最终矩阵，包含直接材料、人工和全部费用类别，运费只计一次。
RD 和 RC 编码均参与识别与归集。JSON 显式序列化，避免 Pyodide Map 读取为零值。
年度由用户选择并与原明细校验；Excel 与数据库使用同一核算年度。

同核算主体、年度、月份为完整快照，重算原子替换该范围，其他主体与月份保留。
旧计算快照及输入文件 SHA256 保留追溯。未知项目、缺少平台、总额不符均整批拒绝入账。
金额按分传递，允许负数冲销。合计在数据库中计算。
上传一次最多处理原模板允许的 18 个项目；平台数据库的 41 个项目不受该模板槽位限制。

## 本地运行

网页：http://127.0.0.1:3220/projects
启动命令：npm run dev:rd-local

数据库持久目录：本副本 .local/postgres（忽略版本控制）。
连接配置：.env.local（忽略版本控制）。
独立本地数据库 rd_finance_preview；Unix socket /tmp/suyu-rd-socket.XRJwLm，标识端口 55447，不监听数据库 TCP。
迁移脚本和原始清单导入脚本位于 database/rd，需使用迁移身份运行。
导入同编码已有项目时保留项目 ID 及台账，补充平台关联；遇到冲突中止。
线上数据库迁移、权限更新和发布本次均未执行。
