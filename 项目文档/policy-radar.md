## 每轮执行同一条防漏链路

```bash
npm run sync:policies             # 前置政策测试 → 来源采集 → 正文／附件续查 → 判定 → 守恒 → 链接核验 → 网站数据
npm run check:policy-integrity    # 网站数据、去向台账及规则版本核对
npm run sync:policies -- --resume # 同一套测试和验收，跳过索引，续读正文／附件
npm run sync:policies -- --cached # 同一套测试和验收，仅重算缓存；不重新联网核验来源或链接
npm run check:policy-links       # 单独检查真实项目的原文、附件及关联入口
```

不得用旧脚本绕过前置测试。测试或守恒失败，禁止替换上一有效数据。缓存重算时间不是原文核验时间，页面明确显示重算口径。

## 发现、真实性、资格分开

发现入口覆盖奖补、资助、兑现、申领、领券、预评审等。赛道词、旧标题年份、低分、未知窗口不用于静默删除已发现候选。所有候选进入正文核查队列；已读不等于真实项目，更不等于企业可申报。

只有官方原文与标题明确关联、有具体申请路径和支持结果，才确认为真实事项。新闻、结果公示、普通供给登记、税务文件及免申即享不得混入主表。延期文件通过明确关联补充原事项，不能按相似标题猜日期。

三家公司的资格审查必须完整、匹配当前政策 contentHash、各自档案版本及有效期。缺证据保持待核实，不能用苏州资料代替杭州或连云港。企业材料只读，不发布私有财务、工资或证件。

## 四类台账、两个页面视图及防漏检查

| 数据集合 | 前端入口 | 边界 |
| --- | --- | --- |
| policies | 可申报 → 本区全部／收藏 | 性质已确认，资格或窗口可仍待核实，逐条标注 |
| reviewQueue | 隐藏，仅后台续查 | 原文未读、关联未知、政策依据等，不计入页面 |
| historyPolicies | 不提供页面入口 | 本批截止，仅留数据台账用于下一批追踪 |
| excludedRecords | 隐藏，仅后台审计 | 非项目、不适用和补充文件及其依据 |

candidateIds、recordLedger、collectionCounts 和判定计数必须守恒，每条输入只能有一个可追溯目标。eligibleCombinations 还校验每个已核实的“项目×企业”组合没有被合并吞掉。同名但证据、期限或企业结论不同的记录不能简单合并，共享 URL 的独立事项保持独立。

前端通过 `applicationFeedItems` 统一限定为有效 `policies`，再搜索、分页，每页 30 条。“本区全部”包含已收藏和未收藏；“收藏”只取该集合与收藏 ID 的交集。线索、排除与历史不能借旧收藏或搜索重返页面。后台全量台账和收藏 ID 保留，合并别名继续迁移。

按 2026-09-08 最新展示要求，隐藏分类切换、本区未收藏、跨区收藏、企业／状态／支持类型／地区下拉筛选、清空筛选及覆盖核查面板，同时移除隐藏过滤状态。仅保留“可申报”下两个入口、原有全局搜索、项目详情、分页及页尾简短更新时间／核查状态。不改变判定算法，待核实项目不会因入口名称被改成已核验可申报。具体契约见规则第十七节；本项完成不代表第十六节误排与期限缺口已落实。

## 续查、附件及覆盖缺口

正文按最久未尝试优先，资金词只辅助同等等待排序，每条结果立即保存检查点。indexRevision 不一致不得恢复旧检查点覆盖新索引。正文或附件变化重新计算资格绑定哈希。

苏商通、江苏结构化索引、苏州政策库、吴江搜索、浙江企业之家、杭州科技和苏州企业服务接口保存分页进度，并重读首页捕获新增。浙江企业之家查询全状态及杭州各区县。苏州企业服务当前申报接口仍有状态范围限制，公开显示未完成。无总页数不凭短页认定完整；后页、单个地区或关键词失败保留已读记录及续查位置。HTML 缺少完整水位、科技部页面缺少已验证分页机制等仍保留覆盖缺口。

PDF、Word、XLSX 支持正文提取。PDF 无文字层须逐页 OCR 核验；页数或字数超额、未读页、不支持格式和附件失败不得冒充完整读取。

自动化脚本/policy-integrity.mjs 维护 43 个资金复核方向和部门／区县来源矩阵；数据配置/policy-watchlist.mjs 保留持续核查入口。来源地址未校验不声明有效覆盖，方向不是现行项目。多指南文件保留待拆任务；只有有原文定位的 applicationItems 才生成独立子项，不继承父通知／其他子项的期限或资格结论。

私有状态在 .policy-cache/：candidates.json（候选）、audit.json（逐项判定）、review-queue.json（读取队列）、details/（检查点）、history/（更新前网站备份），不是公开网页。

## 原文和网站交付

正常采集／续查中，policy-links.mjs 对真实项目及附件、关联文件执行 GET、错误页、重定向、标题和文件签名核验。失败时只查证据支持的同标题官方入口或历史副本，不猜 URL、不绕过登录或验证码。缓存重算也必须执行链接核验；每次同步和单独链接检查均同步更新页面使用的 policy-applications.json。

public/policy-sources/ 查阅页和公开附件副本保留来源、获取时间与限制，转义内容，不执行来源脚本。历史副本不等于最新原文；缺少副本显式说明。待查线索按钮标注“待核”，不承诺完整可用。

写入 public/policies.json；已有构建时同步 dist/client/policies.json 及公开来源副本。交付核对实际 HTTP 数据与两份文件哈希一致。不把测试 fixture 写入正式清单。

前端对已核实为同一事项的“关于转发”记录作原文归并：原始发布通知作为唯一主条目和主链接，属地转发页保留为关联材料并迁移收藏别名。没有已读取、标题绑定通过的原始通知时不隐藏转发记录。智能电网事项当前以国家能源局原始通知 `most-notices-483b0995` 为主，江苏转发通知 `jiangsu-scitech-xml-613fbf6` 保存 2026-09-11 17:00 的属地报送节点；国家网报截止为 2026-09-13 16:00。
