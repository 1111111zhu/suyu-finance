# 三家溯驭：资金申报漏项排查

核查日期：2026-09-08，北京时间。对应网站：`http://localhost:3000/policy`。

## 结论与范围

当前网站不能作为三家公司“所有能申报项目”的完整清单。问题既包括外部来源漏采，也包括已采到的资金线索没有继续核验、项目子项未拆分、时间和属地误判。

本次全量扫描了网站已有的 3,263 条候选并导出逐条索引；对重点资金事项查了外部通知。**这不等于逐篇人工读完 3,263 份原文，也不等于穷尽政府全部渠道，更不代表三家公司已满足下列项目条件。**

本次交付是漏项诊断及补查清单，没有修改网站生产数据、匹配器或原规则，没有将未核验线索直接加入“可申报”。

## 五、造成遗漏的本网站具体机制

| 问题 | 本地位置／证据 | 造成的后果与正确处理 |
| --- | --- | --- |
| 先用标题判定，再决定是否读正文 | `自动化脚本/project-assessment.mjs:20`、`自动化脚本/sync-policies.mjs:341` | “申领、领用、领取、兑付、预评审”及只有“补助／奖励”的标题可能落入 lead，随后永远进不了正文队列。应扩大**核查入口**，但最终准入仍须原文证据，不是简单把所有 lead 公开 |
| 年份混为一谈 | `自动化脚本/project-assessment.mjs:86` | 标题业绩年度早于本年且时间未知就隐藏；“2026 年申请 2025 年费用补助”会有风险。业绩年度、通知日期、申请年度必须分字段 |
| 截止日从附件无关日期抽取 | 本地苏州先进制造资金 2024-12-31、江苏制造强省 2026-01-01 | 项目实施期、数据统计期、表格日期不能当申请截止；误判过期后还会跳过详情核验 |
| 地名正则误伤 | `自动化脚本/sync-policies.mjs:426` 起的 `explicitCity`；已有“年度市”“年度全市” | 应使用行政区划和发布部门结构，不从任意中文“……市”推断属地；且须识别市区不含赣榆等例外 |
| 依赖汇总源原文链接但未核标题一致 | 数改券指向无关案例函 PDF | 正文标题、发文机关、文号、年度、附件关联需比对；可访问不等于有效证据 |
| 主体档案和资格审查未接通 | `companyAssessment()` 要求 `profile.companies[id].version`；现有档案仍是单主体 `fields + matcherProfile` | 三家独立审查所需版本不存在，没有逐条件完整核验记录，所以 eligible 为 0；应完善证据流，不应降门槛假装可申报 |
| 汇总通知没有稳定拆出独立资助方向 | 一个来源文档对应一条候选，制造强省、科创指数惠等指南包含多个事项 | 支持方向、窗口、对象、金额不一致的可独立申请子项应分别建模，共用同一通知证据；结果、公示只关联而非新增 |
| 来源可访问被误读为来源穷尽 | 42 个源均 ok，但苏商通 `incomplete=true`；若干源 count=0；部分固定分页和数量上限 | ok 只代表某次请求，不能替代分页水位、历史回溯、零结果诊断及跨部门覆盖 |
| “待查 60 条”口径遗漏大量线索 | `自动化脚本/policy-feed.mjs:60` 只计特定 application | 应分别统计未读 lead、附件失败、窗口未知、资格未知、真实项目待查，避免形成“只剩 60 条”的错觉 |
| 更新链没有自动闭合 | 1 月中小微贴息与 8 月扩围 | 旧文件没有新标题关键词，也要沿文号和修订／补充关系回查，过期金额不得继续展示 |

这些问题与 `规则.md` 中“完整原文、三主体独立、跨年度兑现、全范围覆盖、子项拆分”的目标有差距；仅写规则或继续增加若干标题不能证明完成。

## 六、补录验收口径

1. 当前窗口有效且项目性质真实，但公司条件缺证据：进入“真实项目，资格待核实”，逐项列缺什么；不得无声消失，也不得标成已可申报。
2. 只有一般办法或媒体线索：进入内部核查队列，并给下一动作；不得混入项目主表。
3. 已截止真实申报：保留年度库及后续批次跟踪，不展示为当前可申请；延期须有对应批次官方依据。
4. 免申即享、税务优惠、银行风险补偿、公示名单、一般办事与新闻：不充当新项目申报。确有企业利益的免申事项可单独作为“权益／兑现提醒”，不计入申报总数。
5. 钱给谁、谁申请、谁承担合同与支出必须明确。三家企业各用自己的主体、账户、人员、资质、财务和属地；集团关系不自动满足条件。
6. 每个资金子项给出主管部门、受理区县、官方原文、指南、实际企业截止、金额公式及上限、可否叠加、待补资料。不能以贷款额度、总财政盘子或项目最低投入冒充企业补助金额。
7. 验收覆盖“国家—省—市—真实区县／园区 × 主管部门 × 资金方向 × 受理／预审／兑现阶段”。未查到、读取失败、登录受限、尚无当期通知都需留下状态，不能用零结果通过。
