# 企业微信访问权限配置

统一入口和左侧菜单继续使用 3220 首页。权限由后端执行，隐藏菜单不能替代授权。

## 正式配置

服务器端需要 `RD_DATABASE_URL`、`PAYROLL_DATABASE_URL`、`SUYU_PUBLIC_ORIGIN`（HTTPS 网站源地址）、`WECOM_CORP_ID`、`WECOM_AGENT_ID`、`WECOM_APP_SECRET_FILE`、`WECOM_MANAGER_TAG_ID`、`WECOM_FINANCE_DEPARTMENT_ID`。密钥文件必须仅服务用户可读（0600），不得提交 GitHub。自建应用须有成员、部门及指定经理标签的读取权限，并配置网站可信域名及回调 `/api/auth/callback`。经理标签只按明确成员授权，不因整个部门在标签中而授予经理资格。

普通桌面浏览器使用[企业微信 Web 登录页](https://developer.work.weixin.qq.com/document/path/98152)，支持扫码和企业微信客户端确认；企业微信内置浏览器使用 OAuth 授权。未登录用户访问首页时，配置齐全后自动进入相应登录页。未配置完整时首页提示登录暂未开通，不提供无效的登录跳转。企业微信管理后台应将 `finance.seeextech.com` 配置为该应用的 OAuth 可信域名或 Web 网页授权回调域名，回调地址为 `https://finance.seeextech.com/api/auth/callback`。

`009_access.sql` 在研发数据库创建会话和一次性 OAuth 状态表，运行账号需要这些表的 SELECT/INSERT/UPDATE/DELETE 权限。会话只保存随机令牌哈希，有效期 8 小时；退出删除会话。工资写入审计继续引用现有工资用户表，必须预先配置每名经理的启用账号，用户名为 `wecom:<企业微信 UserID>`。未配置时工资操作拒绝，而不会自动用其他管理员身份。密码应由管理员设为随机不可分发的值，网站仅允许企业微信登录，历史用户名密码入口关闭。

OAuth 使用企业微信官方 `auth/getuserinfo` 换取本企业 UserID，随后核验 `user/get`、`tag/get` 与 `department/list`，不信任前端传来的角色或部门。

## 本机验收

只有 `NODE_ENV` 非 production、显式 `RD_LOCAL_PREVIEW=1`、精确本机地址 `127.0.0.1:3220` 和非跨站请求同时满足，才允许本机验收身份。前端不显示或提供身份切换。本机验收身份仅由服务器环境 SUYU_LOCAL_PREVIEW_ROLE 决定（finance 或 manager，默认 manager），不读取客户端角色 Cookie。正式身份由企业微信服务器核验。此功能不会在生产环境启用，不能证明真实企业微信配置已完成。

本机工资操作账号使用 `SUYU_LOCAL_PAYROLL_ACTOR` 指定的开发账号，默认 `admin`；数据与账号仅作本机验收。财务身份访问工资 HTML、静态图片、工资 API、研发导出和来源文档均应返回 403；研发人工费用汇总正常。真实企业微信 OAuth 需正式凭据与可信域名后另行验收。

工资 API 已提供 `app/api/payroll/[...path]` 同源适配，不需要第二端口。生产运行时须确认框架执行根目录 middleware 保护 `public/salary` 等静态资源，反向代理不得绕过网站直接公开工资目录或归档目录。
