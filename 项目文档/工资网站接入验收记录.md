## 浏览器实测

在隐藏的本机浏览器标签页连接独立测试 API，完成以下真实操作：

1. 登录虚拟测试管理员，确认默认演示批次保存按钮禁用。
2. 新建空白批次，确认员工数为空、没有带入演示员工；保存为服务器版本 1。
3. 上传临时生成的虚拟花名册，保存含解析资料及结果的版本 2。
4. 退出登录，确认服务器按钮不可用；重新登录，从服务器列表恢复为新的本机副本。
5. 验证员工、部门和参考工号随服务器草稿恢复。
6. 发现并修复上传完成后保存按钮未解除禁用的问题；刷新代码后再次替换资料，直接保存为版本 3。

验证完成后关闭临时浏览器页、停止临时 API，并收到测试数据库清理完成结果。浏览器实测未上传任何真实员工资料。

## 保护与范围

- 正式库名、生产环境和未显式启用的演示导入均被拒绝；迁移/启动不自动 seed。
- 登录会话存哈希，退出可撤销；过期、停用账号、限流及并发失败次数已验证。
- 写请求检查同源、Cookie 会话与 CSRF；跨账号草稿访问被拒绝。
- 仅明确的可信代理可提供真实客户端 IP；真实 HTTP 用例验证代理后不同客户端的失败额度独立。
- 草稿版本冲突不覆盖旧数据；响应丢失后保留完全相同的请求内容重试。
- 服务器草稿不会自动生成员工档案或确认正式工资；未完成的人员关联可以先保存。

本机没有 Docker，未运行真实容器/Nginx。已经提供 API Dockerfile、Compose 叠加配置、Nginx 路由示例和管理员部署步骤。生产密码、域名、数据库角色及存储机器的接口仍由部署环境提供，云服务器未部署。
